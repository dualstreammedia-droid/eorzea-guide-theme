## 重要な注記（ネットワーク制限について・10週連続）

本セッションの実行環境では、egressプロキシのポリシーにより
`www.eorzea-guide.com` への直接アクセス（curl・WebFetchによるHTTPリクエスト）が
今回もブロックされました。

curl（`https://www.eorzea-guide.com/sitemap.xml`、`-v`で確認）:

```
* Establish HTTP proxy tunnel to www.eorzea-guide.com:443
> CONNECT www.eorzea-guide.com:443 HTTP/1.1
< HTTP/1.1 403 Forbidden (agent proxy: no rule or network setting allows this host)
* CONNECT tunnel failed, response 403
curl: (56) CONNECT tunnel failed, response 403
```

環境設定（`get_environment`）を確認したところ、現在のネットワークアクセスは
`limited`で、許可ホスト一覧（`allowed_hosts`）は空であり、本サイトは許可リス
トに含まれていないことを再確認した。

今回は`update_environment`で`www.eorzea-guide.com`を許可リストに追加する変更
を申請したが、本実行はユーザーが立ち会っていないスケジュールタスクによる自
動実行であるため、承認を得られず申請は自動的に却下された
（「nobody is present on this routine run」）。

前回までの9回（2026-09-21、2026-09-28、2026-10-05、2026-10-12、2026-10-19、
2026-10-26、2026-11-02、2026-11-09、2026-11-16）と同様、ドメイン単位でのegress
拒否と考えられる。そのため、以下の手順1〜3（サイトマップ取得、全URLのステー
タスコード確認、トップページの直接確認）は今回も実施できていません。手順4
（WebSearchによるインデックス状況のサンプリング確認）のみ実施できました。

**これで2026-09-21から10週連続で、本チェックの核心部分（ステータスコード確
認）が完遂できていません。** セッション環境固有の既知の制約が是正されないま

## 所見と推奨アクション

- **10週連続で**ステータスコードチェック（手順1〜3）を完遂できておらず、「全
  URL正常」と断定することはできない。本チェックの本来の目的（リンク切れ・サ
  ーバーエラーの早期発見）を10週間（約2ヶ月半）にわたり果たせていない状態が
  続いており、引き続き以下のいずれかの対応を強く推奨する。
  1.（最優先・恒久対応）このスケジュールタスクを実行するセッション環境の
     egressネットワークポリシーを見直し、`www.eorzea-guide.com`（および
     ニュース調査で利用するfinalfantasyxiv.com、famitsu.com、
     dengekionline.com等の関連ドメイン）を許可リストに追加する。今回も本セ
     ッションから環境設定変更（`www.eorzea-guide.com`の許可リスト追加）を申
     請したが、自動実行のため承認者が不在で変更できなかった。ユーザーが本ス
     ケジュールタスクを手動で「今すぐ実行」し、その場で表示される承認リクエ
     ストに応答する、または環境設定画面の「Network access」から直接ドメイン
     を追加することで対応可能。
  2. 上記の変更が難しい場合は、`www.eorzea-guide.com`へのegressが許可された
     別の環境・セッション（または手元の端末）で本チェックを再実行する。
  3. 応急対応として、ネットワーク制限のない環境から
     `curl -o /dev/null -s -w '%{http_code}\n' <URL>`形式で、サイトマップ記
     載の全URLを1秒間隔で巡回する。
- **継続中の懸念点（6週連続で悪化）**: WebSearchによる間接確認で、
  2026-10-19・2026-10-26・2026-11-02・2026-11-09・2026-11-16・2026-11-23の6
  回連続で、`site:`演算子を含む検索および サイト名そのものでの検索でも、当サ
  イトのURLが完全にヒットしなくなっている。2026-10-12まではキーワード検索で
  記事URLが複数件ヒットしていたことを踏まえると、一時的な検索エンジン側の表
  示揺れではなく、実際のデインデックス（検索結果からの除外）が進行・固定化し
  ている可能性が高い。Google Search Console等の一次情報（カバレッジレポー
  ト、URL検査ツール、手動対策の有無）での確認を最優先で実施することを強く推
  奨する。
- 本チェックの核心部分（ステータスコード確認）が実施できない状態が10週間（約
  2ヶ月半）続いており、運用上の優先事項として、早期にegressポリシーの見直し
  （上記1）を実施することを改めて強く推奨する。
