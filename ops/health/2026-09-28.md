# サイトヘルスチェック 2026-09-28

対象サイト: エオルゼア攻略ガイド（https://www.eorzea-guide.com）
実施日時: 2026年9月28日（日本時間）

## 重要な注記（ネットワーク制限について）

本セッションの実行環境では、egressプロキシのポリシーにより
`www.eorzea-guide.com` への直接アクセス（curlによるHTTPリクエスト、WebFetch
によるページ取得のいずれも）がブロックされました。

```
curl: (56) CONNECT tunnel failed, response 403
[agent-proxy] connect_rejected（組織ポリシーによる拒否、または宛先へ到達不可）
host: www.eorzea-guide.com:443

WebFetch: {"error_type":"EGRESS_BLOCKED","domain":"www.eorzea-guide.com",
"message":"Access to www.eorzea-guide.com is blocked by the network egress proxy."}
```

トップページ（`/`）と`sitemap.xml`の両方で同一のブロックを確認しており、
パス単位ではなくドメイン単位のブロックであることを確認済み。そのため、
以下の手順1〜3（サイトマップ取得、全URLのステータスコード確認、トップ
ページの直接確認）は実施できていません。手順4（WebSearchによるインデッ
クス状況のサンプリング確認）のみ実施できました。

前回（2026-09-21）のレポートでも全く同じ制限が発生しており、**2週連続で
本チェックが完遂できていません**。セッション環境固有の既知の制約が継続
している状態です。正確なヘルスチェックには、このドメインへのegressが
許可された環境（または手元の端末・CI）での実行が必要です。

## 所見と推奨アクション

- **2週連続で**ステータスコードチェック（手順1〜3）を完遂できておらず、
  「全URL正常」と断定することはできない。未実施のまま済ませず、以下の
  いずれかの対応を推奨する。
  1. （最優先）このスケジュールタスクを実行するセッション環境の
     egressポリシーに `www.eorzea-guide.com`（および必要であれば
     サイトマップ配信元・画像CDN等の関連ドメイン）を許可リストとして
     登録する。2週連続で同一の原因により手順1〜3が未実施となっており、
     恒久対応が必要な段階にある。
  2. 上記が難しい場合は、`www.eorzea-guide.com` へのegressが許可された
     別の環境・セッションで本チェックを再実行する。
  3. 応急対応として、手元の端末やCIなど、ネットワーク制限のない環境から
     `curl -o /dev/null -s -w '%{http_code}\n' <URL>` 形式で
     サイトマップ記載の全URLを巡回する。
- WebSearchによるインデックスサンプリングでは異常は見られず、検索エンジン
  経由の露出自体に緊急の問題は無いと考えられる。ただしこれはHTTP
  ステータスや実際のページ表示を保証するものではない点に注意。
- 次回以降も同じネットワーク制限が続く場合、ops/health配下のレポートは
  毎回「直接アクセス不可」の注記付きとなる見込み。運用上、早期に
  egressポリシーの見直しを行うことを強く推奨する。
