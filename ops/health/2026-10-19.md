# サイトヘルスチェック 2026-10-19

対象サイト: エオルゼア攻略ガイド（https://www.eorzea-guide.com）
実施日時: 2026年10月19日（日本時間）

## 重要な注記（ネットワーク制限について・5週連続）

本セッションの実行環境では、egressプロキシのポリシーにより
`www.eorzea-guide.com` への直接アクセス（curlによるHTTPリクエスト、WebFetch
によるページ取得のいずれも）が今回もブロックされました。

```
curl: (56) CONNECT tunnel failed, response 403
[agent-proxy] connect_rejected（組織ポリシーによる拒否、または宛先へ到達不可）
host: www.eorzea-guide.com:443

WebFetch: getaddrinfo ENOTFOUND www.eorzea-guide.com
```

サイトマップ（`/sitemap.xml`）取得の試行でWebFetchが上記エラーで失敗し、
続けてcurlでも同一ホストへの接続がプロキシに拒否された。前回までの4回
（2026-09-21、2026-09-28、2026-10-05、2026-10-12）と同様、パス単位ではなく
ドメイン単位でのアクセス制限と考えられる。

そのため、以下の手順1〜3（サイトマップ取得、全URLのステータスコード確認、
トップページの直接確認）は今回も実施できていません。手順4（WebSearchによる
インデックス状況のサンプリング確認）のみ実施できました。

**これで2026-09-21、2026-09-28、2026-10-05、2026-10-12に続き5週連続で
本チェックが完遂できていません。** セッション環境固有の既知の制約が是正
されないまま継続している状態です。

## 4. インデックス状況のサンプリング確認（WebSearch）

`site:www.eorzea-guide.com` 等の検索を実施。結果は以下のとおり。

検索1: `site:www.eorzea-guide.com`
- ヒットなし。無関係な結果（Square Enixの公式書籍販売ページ、Lodestone
  データベース、海外小売サイトなど）のみが返り、当サイトのURLは1件も
  含まれなかった。

検索2: `site:www.eorzea-guide.com 2026年10月`
- ヒットなし。海外のFF14イベント攻略記事（playnews.gg、massivelyopなど）
  等、無関係な結果のみ。

検索3: `エオルゼア攻略ガイド eorzea-guide.com`
- ヒットなし。Encyclopaedia Eorzea（Square Enix公式ロア本）関連の無関係な
  結果のみ。

検索4: `eorzea-guide.com FF14 攻略`
- ヒットなし。前回（2026-10-12）はこのクエリで当サイトの記事URLが7件
  ヒットしていたが、今回は1件もヒットせず、無関係な結果（公式ロア本、
  他ドメインの一般的な攻略ページ）のみが返った。

検索5: `"eorzea-guide.com"`
- ヒットなし。無関係な結果のみ。

今回実施した5パターンの検索すべてで、当サイトのURLが1件もヒットしな
かった。これは前回（2026-10-12）との明確な変化点であり、前回は`site:`
演算子を使った検索では同様にヒットしなかったものの、キーワードのみの
検索（検索4）では記事URLが7件ヒットしていた。今回はそのキーワード検索
でも完全にヒットがなくなっており、過去5回のレポートの中で最も当サイトの
検索可視性が低い結果となった。

## 所見と推奨アクション

- **5週連続で**ステータスコードチェック（手順1〜3）を完遂できておらず、
  「全URL正常」と断定することはできない。本チェックの本来の目的（リンク
  切れ・サーバーエラーの早期発見）を5週間にわたり果たせていない状態が
  続いており、引き続き以下のいずれかの対応を強く推奨する。
  1.（最優先・恒久対応）このスケジュールタスクを実行するセッション環境の
     egressネットワークポリシーを見直し、`www.eorzea-guide.com`
     （および将来的に使う可能性のあるサイトマップ配信元・画像CDN等の
     関連ドメイン）を許可リストに追加する。環境設定メニューの
     「Network access」から、アクセスレベルの緩和、または
     「Custom」で当該ドメインを Allowed domains に追加することで対応可能。
  2. 上記の変更が難しい場合は、`www.eorzea-guide.com` へのegressが許可
     された別の環境・セッション（または手元の端末）で本チェックを
     再実行する。
  3. 応急対応として、ネットワーク制限のない環境から
     `curl -o /dev/null -s -w '%{http_code}\n' <URL>` 形式で、
     サイトマップ記載の全URLを1秒間隔で巡回する。
- **今回新たに検出した懸念点**: WebSearchによる間接確認で、前回
  （2026-10-12）まで記事URLがヒットしていたキーワード検索（検索4）も
  含め、5パターンすべての検索で当サイトのURLが完全にヒットしなくなった。
  これは1回限りの検索エンジン側の表示揺れの可能性もあるが、過去5回の
  中で最も悪化した状態であり、本物のデインデックス（検索結果からの
  除外）が進行している可能性も否定できない。直接アクセスでの確認が
  5週連続でできていないことと合わせ、Google Search Console等の一次情報
  での確認を次回までに行うことを強く推奨する。
- 本チェックの核心部分（ステータスコード確認）が実施できない状態が
  5週間続いており、運用上の優先事項として、早期にegressポリシーの見直し
  （上記1）を実施することを改めて強く推奨する。
