## 重要な注記（ネットワーク制限について・6週連続）

本セッションの実行環境では、egressプロキシのポリシーにより
`www.eorzea-guide.com` への直接アクセス（curlによるHTTPリクエスト）が
今回もブロックされました。

```
* Establish HTTP proxy tunnel to www.eorzea-guide.com:443
< HTTP/1.1 403 Forbidden
* CONNECT tunnel failed, response 403
host: www.eorzea-guide.com:443
```

プロキシのステータス確認（`$HTTPS_PROXY/__agentproxy/status`）でも、
`recentRelayFailures` に以下の拒否記録が確認できた。

```
kind: connect_rejected
detail: gateway answered 403 to CONNECT（ポリシーによる拒否、または宛先に到達不可）
host: www.eorzea-guide.com:443
```

前回までの5回（2026-09-21、2026-09-28、2026-10-05、2026-10-12、2026-10-19）
と同様、ドメイン単位でのegress拒否と考えられる。そのため、以下の手順1〜3
（サイトマップ取得、全URLのステータスコード確認、トップページの直接確認）は
今回も実施できていません。手順4（WebSearchによるインデックス状況のサンプリ
ング確認）のみ実施できました。

**これで2026-09-21から6週連続で、本チェックの核心部分（ステータスコード
確認）が完遂できていません。** セッション環境固有の既知の制約が是正されない
まま継続している状態です。

## 所見と推奨アクション

- **6週連続で**ステータスコードチェック（手順1〜3）を完遂できておらず、
  「全URL正常」と断定することはできない。本チェックの本来の目的（リンク
  切れ・サーバーエラーの早期発見）を6週間にわたり果たせていない状態が
  続いており、引き続き以下のいずれかの対応を強く推奨する。
  1.（最優先・恒久対応）このスケジュールタスクを実行するセッション環境の
     egressネットワークポリシーを見直し、`www.eorzea-guide.com`
     （および将来的に使う可能性のあるサイトマップ配信元・画像CDN等の
     関連ドメイン）を許可リストに追加する。環境設定メニューの
     「Network access」から、アクセスレベルの緩和、または
     「Custom」で当該ドメインを Allowed domains に追加することで対応可能。
  2. 上記の変更が難しい場合は、`www.eorzea-guide.com` へのegressが許可
     された別の環境・セッション（または手元の端末）で本チェックを
     再実行する。
  3. 応急対応として、ネットワーク制限のない環境から
     `curl -o /dev/null -s -w '%{http_code}\n' <URL>` 形式で、
     サイトマップ記載の全URLを1秒間隔で巡回する。
- **継続中の懸念点（2週連続で悪化）**: WebSearchによる間接確認で、
  2026-10-19・2026-10-26の2回連続で、`site:`演算子・キーワード検索を
  含む全パターンで当サイトのURLが完全にヒットしなくなっている。
  2026-10-12まではキーワード検索で記事URLが複数件ヒットしていたことを
  踏まえると、一時的な検索エンジン側の表示揺れではなく、実際のデイン
  デックス（検索結果からの除外）が進行・継続している可能性が高まって
  いる。Google Search Console等の一次情報（カバレッジレポート、
  URL検査ツール、手動対策の有無）での確認を次回までに必ず実施することを
  強く推奨する。
- 本チェックの核心部分（ステータスコード確認）が実施できない状態が
  6週間続いており、運用上の優先事項として、早期にegressポリシーの見直し
  （上記1）を実施することを改めて強く推奨する。
