# サイトヘルスチェック 2026-09-21

対象サイト: エオルゼア攻略ガイド（https://www.eorzea-guide.com）
実施日時: 2026年9月21日（日本時間）

## 重要な注記（ネットワーク制限について）

本セッションの実行環境では、egressプロキシのポリシーにより
`www.eorzea-guide.com` への直接アクセス（curlによるHTTPリクエスト、WebFetch
によるページ取得のいずれも）がブロックされました。

```
curl: (56) CONNECT tunnel failed, response 403
gateway answered 403 to CONNECT (policy denial or upstream failure)
host: www.eorzea-guide.com:443
```

WebFetchでも同一ドメインに対して `EGRESS_BLOCKED` エラーが返り、取得できません
でした。そのため、以下の手順1〜3（サイトマップ取得、全URLのステータスコード
確認、トップページの直接確認）は実施できていません。手順4（WebSearchによる
インデックス状況のサンプリング確認）のみ実施できました。

同様の制限は本リポジトリの他の週次ジョブ（ops/news配下）でも発生しており、
このセッション環境固有の既知の制約です。正確なヘルスチェックには、この
ドメインへのegressが許可された環境（または手元の端末）での実行が必要です。

いません）。

## 3. トップページの状態・最新記事の日付

直接確認: 不可（トップページの取得ができませんでした）。

参考情報（WebSearchの検索結果キャッシュより。一次情報未確認）:
- 検索結果上でサイトは正常にインデックスされている状態が確認できる
  （タイトル・URLが正しく表示されている）。
- 検索結果に表示された記事の一部に、パッチ7.56（2026年9月8日実装、
  ops/news/2026-09-08付近の情報と整合）に言及する記事があり
  （例:「魔獣使い 戦闘システム完全解説｜TP・獣心技連携・活命撃／滅命撃
  【パッチ7.56】」URL上の日付は2026/04/30）、記事が更新され続けている
  可能性はあるが、URLの日付が実際の最終更新日と一致するとは限らないため
  「最新記事の日付」として断定はできない。
- 検索結果で確認できた記事URLの多くは2026年4月〜5月の日付を含んでおり、
  直近1週間以内に新規公開された記事をこのサンプリングだけでは特定できな
  かった。トップページの直接確認ができ次第、最新記事日付を要確認。

## 所見と推奨アクション

- 今週はステータスコードチェック（手順1〜3）を完遂できておらず、
  「全URL正常」と断定することはできない。未実施のまま済ませず、以下の
  いずれかの方法で改めて確認することを推奨する。
  1. `www.eorzea-guide.com` へのegressが許可された環境・セッションで
     本チェックを再実行する。
  2. 手元の端末やCIなど、ネットワーク制限のない環境から
     `curl -o /dev/null -s -w '%{http_code}\n' <URL>` 形式で
     サイトマップ記載の全URLを巡回する。
  3. 恒久対応として、このスケジュールタスクを実行するセッション環境の
     egressポリシーに `www.eorzea-guide.com`（および必要であれば
     サイトマップ配信元・画像CDN等の関連ドメイン）を許可リスト登録する。
- WebSearchによるインデックスサンプリングでは異常は見られなかったため、
  検索エンジン経由の露出自体に緊急の問題は無いと考えられる。ただし
  これはHTTPステータスや実際のページ表示を保証するものではない点に注意。
- 次回以降も同じネットワーク制限が続く場合、ops/health配下のレポートは
  毎回「直接アクセス不可」の注記付きとなる見込み。運用上、egressポリシー
  の見直しを検討することを推奨する。
